# KDisplayMode

Resolution and window mode (Fullscreen / Borderless / Windowed) switching for Unity standalone players on Windows and macOS.

This package does not save settings. `DisplaySettings` is a serializable struct; store it with your project's own save system.

Documentation: https://github.com/vailKAKO/KDisplayMode ([日本語](https://github.com/vailKAKO/KDisplayMode/blob/main/README.ja.md))
